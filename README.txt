[끝말잇기 오프라인 앱 · 깃허브 올리는 법]
1) 깃허브에서 새 저장소(repo)를 만들고, 이 폴더 안의 파일을 전부 올려요 (폴더째가 아니라 안의 파일들 — lib 폴더는 이제 없어요: index.html, dict-pack.json, sw.js, manifest.json, icon-*.png, .nojekyll ...)
2) 저장소 Settings → Pages → Branch: main / (root) → Save
3) 잠시 뒤 생기는 주소(https://아이디.github.io/저장소이름/)를 폰에서 "인터넷 켠 채로 한 번" 열어요. 열리면서 게임이 폰에 통째로 저장돼요.
4) 홈 화면에 추가(설치)하면 앱처럼 열려요. 그다음부터는 인터넷이 없어도 열려요.
   (처음 열 때 몇 초~수십 초 걸려요. 파일이 크고, 사전이 들어 있어서요.)

[고쳐서 다시 올릴 때]
- index.html을 바꿔 올리고, sw.js 맨 위의 VERSION = 'v1' 을 'v2'로 올려요. (안 올리면 폰이 예전 파일을 계속 써요)

[참고]
- 실시간 대전(온라인)은 인터넷이 있어야 해요. 나머지는 오프라인 가능.
- 이 버전은 클라우드 저장(jd-cloud.js)을 뺐어요. 기록은 그 폰 안에만 저장돼요 (다른 폰과 자동으로 안 이어짐 · QR 옮기기/백업으로 옮겨요).
- ranks.json.gz / dict1.json.gz / dict2.json.gz 는 없어도 돼요(사전은 index.html 안에 들어 있음). 있으면 같은 폴더에 같이 올리면 돼요.
